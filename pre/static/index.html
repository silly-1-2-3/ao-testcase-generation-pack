研发模式说明

  • 外部 Qwen API 被主动禁用，这是离线部署的预期状态。
  • 设备检索默认关闭；显式开启后，也只给出 BM25+BGE 候选和审计信息，不自动改写模型输出。
  • 用户可以在审计区域主动应用某个候选；修改只作用于当前网页副本，可撤销，并会写入导出工作簿的修改审计。
  • 当前示例设备库只有 2 条，仅用于验证检索链路，不能作为生产设备指令依据。
  • 接入现场真实数据后，需要重新转换语料、重建 BM25+BGE 索引，并将数据类型改为 production。
  • 实时比较需要 vLLM 同时注册 Base 和 LoRA 两个服务名。
  • 每条 AO 都使用全新的 System + User 消息，不保存上一条 AO 的上下文。
